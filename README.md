# Study Sync Engine ⚙️

A minimalist, local-first file organizer built to survive the chaos of exam prep and technical project building.

I was tired of downloading research papers, coding assignments, and Japanese language resources, only to lose them in a bloated `Downloads` folder. Standard organizers just look at file extensions; I needed something that understands a student's actual workflow. So, I built this.

Study Sync Engine acts as a mechanical sorter for your digital workspace. You click a button, point it at a messy directory, and it instantly routes your PDFs, scripts, and media into structured, distraction-free environments.

## 🚀 The Stack
- **Core Logic:** Pure Python (System agnostic, fast execution)
- **Interface:** Tkinter (Lightweight, dark-mode GUI)
- **Architecture:** Object-oriented and strictly modular

## 🛠️ How It Works
Instead of a massive wall of files, the engine categorizes incoming data into targeted pillars:
- `Literature/` - Textbooks, research papers, and reading materials.
- `Notes & Context/` - Lecture notes and syllabus documents.
- `Media & Assets/` - Design files, diagrams, and reference images.
- `Source Code/` - Python scripts, Jupyter notebooks, and project files.

Built openly to document my progression in systems thinking, clean code practices, and building tools that actually matter.
